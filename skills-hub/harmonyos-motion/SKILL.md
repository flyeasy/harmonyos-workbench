# HarmonyOS Motion

只做一件事：把模糊描述转换为可检索、可讨论、可验证的术语。不要代替完整设计、审查或实现。

## Capability contract

1. **Input**：现象、触发动作、目标设备和可用录屏/日志。
2. **Preflight**：区分动效、性能、生命周期、几何和测试工具问题。
3. **Execute**：给最佳术语、相近概念、诊断分支和可能的 ArkUI 能力。
4. **Verify**：说明需要慢放、帧率、状态或目标证据中的哪一种。
5. **Evidence**：引用观察，不把推断写成平台事实。
6. **Handoff**：实现交给 `harmonyos-design`，完整验收交给 `harmonyos-review`。

## 输出格式

```markdown
**最佳匹配术语** — 一句话定义。

相近概念：1–2 个。
ArkUI 关联：可能的 API、属性或验证方向。
诊断分支：如何区分相似现象。
边界：什么时候不是这个问题。
```

有多个可能时先给最佳匹配，再给最小诊断分支。API 只能写“可能关联”，并提醒按目标 SDK 核验。

## 术语地图

### 输入与反馈

- **按下反馈**：Touch Down 时立即改变局部状态，证明输入已被接收。
- **抬起提交**：抬起且仍在有效目标内时执行动作。
- **焦点态 / 悬停态 / 选中态**：分别表达当前操作目标、指针提示和持久选择。
- **瞬态显现 / 可见期**：临时控件出现及保持可操作的时间窗口。

“按钮滚动后出现但自动化点不到”可能是可见期耗尽、旧坐标或工具延迟，不一定是点击失效。

### 连续手势

- **跟手（Direct tracking）**：对象持续随输入变化。
- **速度继承（Velocity handoff）**：离手动画沿用离手前速度。
- **动画衔接（Animation continuity）**：目标改变时从当前显示状态进入新目标。
- **可打断动画**：动画中可被新输入接管、反向或重定向。
- **边界阻尼 / 回稳 / 抛滑 / 吸附**：越界阻力和离手后的目标选择与稳定过程。
- **速度断层**：跟手与回稳交界处速度突变，常表现为“松手急刹车”。
- **手势竞争 / 识别器不等价**：容器与子节点争夺识别，或自动化手势不满足真实识别条件。

掉帧也会像急刹车。先用慢放、帧长和离手速度区分物理参数与性能问题。

### 转场与编排

- **同层 / 上下层 / 跨层转场**：按信息层级区分状态变化。
- **共享元素 / 共享容器 / 共享动势**：用对象、容器或共同趋势维持空间连续性。
- **默认转场叠加**：自定义或共享转场与 Navigation 默认转场同时作用。
- **错峰 / 数值脉冲 / 状态形变 / 微动效**：用时序和形态表达反馈。
- **重新触发 / 陈旧计时器 / 代际保护 / 显隐竞态**：处理快速重复与异步回调。

### 状态真实性

- **Acknowledged / Pending / Confirmed / Failed**：区分本地接收、处理中、权威成功与失败。
- **乐观更新 / 回滚**：确认前先更新，并在失败时恢复真实状态。
- **虚假完成**：视觉或播报暗示成功，但业务未确认。
- **响应乱序**：旧请求晚到并覆盖新意图。
- **状态轴混合 / 权威源混淆**：一个状态表达多个维度，或把缓存与动画当作远端事实。

“动画在撒谎”通常匹配虚假完成或权威源混淆，不只是缓动问题。

### 生命周期、几何与测试

- **生命周期泄漏**：页面离开后 timer、listener、poll 或 request 仍更新状态。
- **页面内容互串**：旧页面或错误 owner 收到新页面内容。
- **双重安全区**：Window 已避让系统栏，页面又重复加 inset。
- **局部/远端几何耦合**：IME、浮层或本地工具栏错误改变远端内容尺寸。
- **布局抖动**：高频布局属性修改造成反复测量和绘制。
- **测试假阴性**：目标、前置状态、工具或采样时序使真实行为未被观察到。

## 示例

用户说“卡片松手时像先停了一下，再回去”，优先回答：

```markdown
**速度继承缺失（Velocity handoff missing）** — 回稳动画没有沿用手势最后速度，在离手点形成速度断层。

相近概念：动画衔接失败、性能长帧。
ArkUI 关联：核对跟手与回稳使用的曲线、起始速度和目标 SDK 能力。
诊断分支：慢放查看对象是否先归零，同时检查离手帧长。
边界：若位置连续但整帧冻结，优先归为性能长帧。
```
